# Mike's plainer prose in the knowledge manual is deliberate

On 2026-08-31 Mike personally rewrote the save policy in
[knowledge/README.md](../../README.md) and in the `remember` skill. He replaced the
seven-question save test with two non-negotiables and an explanation of working
memory against long-term memory.

His reason, in his words: the way other agents had written it "was horrible,"
and "my updates need to stay."

Those sections read differently from the rest of the toolkit. They are plainer,
longer, and use ordinary words where the surrounding files are terse and dense.
That difference is the point, not an oversight. Do not shorten or restyle them
to match the files around them.

Git blame shows who typed the words. It does not show that the wording is the
thing being protected, which is why this is written down.

## Retired 2026-09-01

Mike asked for the `remember` skill to be leaned down and approved retiring
this file rather than narrowing it. The protection it described no longer
applies. Kept for history only.
