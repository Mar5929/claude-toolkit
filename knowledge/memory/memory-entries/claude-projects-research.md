# Claude Projects comparison with Toolkit OS

On 2026-09-20, a GPT-5.6 Terra research task compared Anthropic's Projects
redesign with Toolkit OS requirements and the delivered Knowledge assessment.
It found overlap in orchestration, shared context and project configuration,
with no demonstrated conflict requiring an immediate Toolkit change.

The recommendation was to preserve portable Markdown/Git records, source
ownership, approvals and recovery while investigating native Projects as an
optional Claude Code integration. This was source research, not a product test;
shared memory behavior, helper lifetime and cross-host support remain unproven.
Mike authorized saving the research, not adopting new product policy.

The [retained report](../../../docs/designs/269-knowledge-system/research/2026-09-20-claude-projects-redesign.md)
contains the source links, requirement comparisons, limits and proposed native
host test. Consult it before repeating the comparison; recheck vendor claims
and availability before making an implementation decision.
