# memory-redesign: the source notes behind the knowledge system

Working material from the 2026 rebuild of project knowledge, kept for history
after the rebuild shipped. It sat in a root `work-items/` folder until the
2026-08-31 toolkit sync moved it here, because work is tracked on the GitHub
board and this material was already spent.

| File | What it is |
|---|---|
| [knowledge-system-north-star.md](knowledge-system-north-star.md) | The target the rebuild aimed at. Cited as the source of `knowledge/specs/knowledge-system.md`. |
| [TODOs.md](TODOs.md) | The build list as it stood during the rebuild. |
| [chatgpt-reports/](chatgpt-reports/) | Two outside reports commissioned during design: functional requirements, and a technical spec with ADRs. |
| [instruction-manuals/](instruction-manuals/) | The operating-system manual drafted alongside the design. |

This is history, not current truth. What the project actually settled on lives
in `knowledge/specs/knowledge-system.md` and the shipped `second-brain` plugin.
A generated `graphify-out/` graph was committed here by accident and was
deleted in the same sync; graphs are rebuilt, never stored.
