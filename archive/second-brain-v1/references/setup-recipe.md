# Archived v1 project setup record

Second-brain v1 is retired. Do not create a Neon database, register a Worker
secret, add a v1 MCP connector, mint a token, install curator agents, or wire v1
capture and recall hooks.

The former per-project recipe remains available in Git history for audit
purposes. It is intentionally absent from the shipped plugin so it cannot be
used as an installer.

For an existing project, use `project-sync` to inventory local v1 integration
files and offer owner-approved deactivation or removal. Do not contact Worker or
Neon resources, read legacy memory, or import anything into v2.
