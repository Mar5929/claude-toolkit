# Archived memory redesign material

Nothing in this folder is current. None of it is a design input for the build
running under issue #215.

The one current design document is
`work-items/memory-redesign/knowledge-system-north-star.md`, one level up. If
anything here disagrees with it, the North Star wins.

## Why these were archived

The redesign was attempted several times before the North Star. Each attempt left
its own requirements document, architecture document, plan, and status file. A
session that opened one of them could not tell which was current, and more than
one build started from a document that had already been replaced.

On 2026-08-21 Mike decided the North Star is the only input and everything else
moves here.

## If you are looking for something here

Read the North Star first. If it does not answer your question, ask Mike rather
than taking an answer from this folder. These documents were written against
designs that no longer exist, so an answer found here is likely to be wrong in a
way that is hard to notice.
