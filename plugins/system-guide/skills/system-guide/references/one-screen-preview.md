# One-screen preview

An enabled session starts with one compact pointer:

```text
System Guide: on; entry: knowledge/system/README.md; capture scope: incomplete; last refresh: 2026-09-10T16:00:00Z.
```

Then ordinary work uses the guide without needing a special request:

| Moment | Expected behavior |
| --- | --- |
| `Which process writes this field, and what could a change affect?` | Open the entry, field index, and linked process or relationship pages; follow current evidence when needed; name the source. |
| `That field really means the household's primary advisor.` | Check the current page and evidence, then show the exact proposed meaning, destination, source, and uncertainty. Do not save it yet. |
| A source snapshot or implementation changes | Refresh affected generated pages, preserve meaning, and flag explanations that need review. |
| Investigation finds three processes that overwrite the same field | Propose the supported cross-process finding if it saves future tracing; leave out the search log and obvious code summaries. |
| A page repeats code or contains obsolete meaning | Remove generated repetition during refresh when evidence supports it; propose the exact meaning cleanup and wait for owner approval. |

If configuration is missing or disabled, skip guide lookup and upkeep. Do not enable it, create guide folders, or store its content in memory or a PRD as a substitute.
