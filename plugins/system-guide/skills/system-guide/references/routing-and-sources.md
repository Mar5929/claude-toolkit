# Routing and sources

## Find order

With the second brain enabled, keep its order:

1. Current work context.
2. Standing rules.
3. Skills.
4. PRDs, memory, and System Guide through their indexes and relevant pages.
5. Past sessions only when the earlier sources do not answer.

Resolve the owner's terms through the glossary before step 4 when one exists. Within step 4, start structure, purpose, connection, and impact questions at the System Guide; required behavior at a finalized PRD; and lasting decisions or lessons at memory. Use the tracker for work-item status. Open the relevant page rather than treating an index as evidence.

Without the second brain, follow project guidance and use the System Guide entry and relevant area index before broad source investigation. Use an existing glossary or project overview when available. Missing second-brain files are skipped without error.

## Put each statement in one home

| Statement | Home |
| --- | --- |
| What the system must do or the business reason for required behavior | PRD |
| How an existing part works, why it matters, or what it connects to | System Guide, when it adds insight or saves substantial investigation |
| A lasting project decision or proven lesson | Memory, when the second brain's save test accepts it; link to guide detail |
| Current work, deployment, or delivery status | Work tracker |
| A repeatable operating procedure | Skill |

Split mixed notes. Never save an existing-system explanation as memory or required future behavior merely because System Guide is off. Use another documented reference home when one exists; otherwise say that no lasting destination is configured.

## Decide what is true

| Question | Strongest source |
| --- | --- |
| What should the system do? | A finalized PRD |
| How is it put together, and what are its parts for? | System Guide |
| What exists now? | The live system |

A proposed PRD is wanted behavior, not proof of current behavior. A captured source is evidence only for its recorded scope and date. Memory does not override these sources. When sources disagree, report the disagreement, dates, and coverage instead of silently choosing or rewriting approved meaning.
