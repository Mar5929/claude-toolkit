## Memory save permission

Per-save approval is required by default. Enabling automatic memory saves needs
the owner's explicit project-specific grant; it covers memory lifecycle operations,
never PRDs. When granted, use frontmatter fields `memory_auto_save: true`,
`memory_permission_by`, `memory_permission_date`, `memory_permission_source`, and
`memory_permission_scope`. Record the actual grant once here; set
`memory_auto_save: false` when revoked and preserve its historical source.
No template or installation step enables this permission.
