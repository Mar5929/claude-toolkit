# Captured topic entry template

A topic's `ai-external-knowledge/<topic>/README.md` provides navigation metadata:

```yaml
---
group: <short topic heading>
summary: <coverage and when useful, one line under 200 characters>
source: <original source URL>
captured_at: <actual YYYY-MM-DD>
---
```

Keep a title, original source address, capture/refresh date, relevant version when
known, and links to the captured pages. Preserve original captured text. The entry
is project navigation, not memory: no approval/confidence/status fields required.
Project conclusions live with their own owner. Rebuild the outside-documentation
index on capture, refresh, move or removal. Check freshness before relying on it.
