# Project knowledge

Reusable, non-obvious technical and project understanding that can prevent
future mistakes or repeated investigation.

This folder does not own required product behavior, raw debugging output, or
obvious descriptions of nearby code.

Every document here carries a `Basis:` line under its one-sentence summary,
saying whether the understanding was observed, owner-confirmed, taken from a
source, or inferred and unconfirmed.
