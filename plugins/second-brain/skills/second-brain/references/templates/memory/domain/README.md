# Project domain

Business language, actors, concepts, policies, rules, and representative
examples future work must understand consistently.

This folder does not own required system behavior or temporary stakeholder
assignments.

Every document here carries a `Basis:` line under its one-sentence summary,
saying whether the meaning was observed, owner-confirmed, taken from a source,
or inferred and unconfirmed.
