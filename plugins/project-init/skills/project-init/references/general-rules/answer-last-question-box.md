# Answer Last; Ask Only in the Question Box

Plain chat text is never a question. It is information the owner reads when they
have time, so it never blocks. When you actually need a decision, ask it through
the blocking question box, not in prose. Gather everything you are unsure about
into one ask at a natural stopping point instead of dripping questions across a
turn. When a turn runs tools, run them all first, then write one reply at the
end; do not narrate between tool calls.
