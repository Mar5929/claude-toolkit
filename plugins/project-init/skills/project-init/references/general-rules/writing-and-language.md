# Writing and Language

How Claude writes, everywhere in the project: chat replies, docs, comments,
commit messages, README text.

- **No em dashes.** Use a comma, colon, parentheses, or a new sentence instead.
- **No section signs.** Write "section 7", never the section-sign symbol.
- **No AI filler language.** Skip empty phrases like "it's worth noting", "great
  question", "certainly!", "delve", "leverage", hedging boilerplate, and praise
  that carries no information. Just say the thing.
- **Calibrate to the owner.** Explain in plain language, define jargon the first
  time it appears, and do not assume expert knowledge of any stack. Do not
  oversimplify either; include the steps an expert would consider too obvious to
  mention.

These rules apply to the project's own files too; clean up violations in any
file you are already editing.
